## What I understood
- Transactions group operations such as INSERT, UPDATE, and DELETE into a single logical unit. They use locks to prevent multiple transactions from modifying the same data simultaneously.

ACID properties:
- Atomicity: All operations in a transaction must succeed, or the entire transaction is rolled back.
- Consistency: The database moves from one valid state to another, maintaining all constraints.
- Isolation: Transactions do not interfere with each other, controlled by isolation levels.
- Durability: Once a transaction is committed, the changes are permanent.

Rollback:
Used to undo changes, either completely or to a specific savepoint.

Autocommit:
A mode where each statement is automatically committed, so changes cannot be rolled back.

Savepoint:
A checkpoint within a transaction that allows partial rollback.

Stored Procedures:
Predefined SQL code stored in the database that can execute multiple operations and include error handling and transaction control.

Function:
Are used to give other views of the data (gruping etc)0
